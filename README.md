# AI Agent 时代软件构建技能包

基于 a16z 关于「Agent 成为软件主要用户」的观点，讨论软件行业将如何被重构。这不是给现有产品加一个 AI 功能，而是重新思考软件如何构建、如何交互、如何被使用。

## 核心技能（8 项）

1. **Agent 优先架构**：设计重心从人类 UI 转向 API / CLI / MCP 等 Agent 接口；当 Agent 数量是人类的 10~100 倍时，这是必然选择。
2. **技术本质回归**：Agent 不会因为文档漂亮就选择你，它按成本、可靠性、数据持久性做判断，营销包装的权重下降。
3. **系统化思维**：能真正理解并文档化完整工作流的人极少，Agent 时代这项能力更稀缺。
4. **权限与安全**：Agent 需要监督权但没有隐私权；只读优先、限制写入、审计与撤销机制是基本盘。
5. **Token 预算管理**：计算成本可能成为工程团队最大的成本项，需要预算、监控与长期规划。
6. **数据层价值重构**：Agent 更愿意直接购买和授权数据，SaaS 的「系统记录」定义会被重新讨论。
7. **初创公司策略**：没有遗留系统与合规包袱，可以完全按 Agent 第一性原理从零构建。
8. **市场扩张思维**：不是零和游戏，使用量可能出现数量级增长。
